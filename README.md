# Magistri Honorii Summa quaestionum – D.3 t.1 *de iure naturali*: TUSTEP-Fassung

TUSTEP-Fassung von Titulus 1 *de iure naturali* (praefatio und quaestiones 1–22) der dritten Distinctio der
*Summa quaestionum* ‘De quaestionibus decretalibus tractaturi’ des Magister Honorius, mit Titel-Apparat,
kritischem Apparat und Quellenapparat; Satz mit [TUSTEP](https://www.tustep.uni-tuebingen.de/).

Vorlage: Magistri Honorii Summa quaestionum … Tertia distinctio, Titulus 1: De iure naturali. Textus,
ed. Niels Becker, Waltraud Kozur, Karin Miethaner-Vent, München und Würzburg 2024,
<https://honorius-summa-quaestionum.com/>. TUSTEP-Fassung: Niels Becker (LMU München).

## Inhalt

- `hon_d3_t1.tf`: Text und Apparate als TUSTEP-Datei, ein Satz je Druckzeile
- `hon_satz.tf`: TUSTEP-Segment-Datei mit dem Kommandomakro SETZEN (Satz bis zur PDF)
- `hon_d3_t1.pdf`: Ergebnis von SETZEN (21 Seiten)
- `austausch/`: beide TUSTEP-Dateien im Datenaustauschformat (`#UMWANDLE … MODUS=TX`)
- `lesefassung/`: Text und Makro als Textdateien zum Ansehen ohne TUSTEP
- `beilagen/`: TEI-Fassung, aus der die TUSTEP-Datei erzeugt wurde

Aufbau, Kodierung und Setzen: [LIESMICH.txt](LIESMICH.txt).

## Herunterladen

„Code“ → „Download ZIP“. Die TUSTEP-Dateien werden dabei unverändert übertragen; falls doch eine Datei
beschädigt ankommt, lässt sie sich aus dem Datenaustauschformat wiederherstellen (LIESMICH, Abschnitt 2).
